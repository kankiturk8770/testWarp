# Kanki Warp

کلاینت شخصی اندروید برای **Cloudflare WARP**. این برنامه سرور خودش را ندارد: یک اکانت رایگان WARP می‌سازد و از
دروازه‌های کلادفلر بیرون می‌رود. ایده و مسیر اتصال از پروژه‌ی [RIX-AETHER](https://github.com/RIX-REZA/RIX-AETHER) گرفته شده؛
هسته همان [Aether](https://github.com/CluvexStudio/Aether) است (Rust) که CI از سورس می‌سازد. کد برنامه مال خود ماست.

## تازه‌های نسخه 0.3.0
دو حالت «کاربر عادی» و «کاربر گیمر»: گیمر با Amnezia/WireGuard مستقیم روی گوشی و اسکن بهترین مسیر بازی؛ عادی با «آی‌پی سفید» برای هر پروتکل.

## مسیر اتصال، از ۰ تا ۱۰۰
```
برنامه‌های گوشی → TUN اندروید → hev-tun2socks → SOCKS5 روی 127.0.0.1:1819
  → هسته‌ی Aether (TCP/IP داخل برنامه، smoltcp) → تونل MASQUE یا WireGuard → دروازه‌ی کلادفلر → اینترنت
```
1. **TUN** (`WarpService.openTun`): همه‌ی ترافیک گوشی (IPv4 و IPv6)، DNS ‏1.1.1.1. خود برنامه بیرون می‌ماند تا ترافیک هسته به کلادفلر دوباره داخل تونل نرود.
2. **زنجیره‌ی پروتکل** (`Options.chain`): انتخاب تو، بعد پروتکلی که دفعه‌ی قبل کار کرد، بعد MASQUE-H2 ← Gool ← H3 ← MASQUE² ← WireGuard (حداکثر ۳ تا؛ جایگزین‌ها با تکه‌تکه کردن).
3. **هسته** (`Engine.startCore`, `libaether.so`)، داخل خودش:
   - **اکانت:** اولین بار با API کلادفلر (`api.cloudflareclient.com`، مثل اپ رسمی WARP اندروید) ثبت‌نام می‌کند: کلید WireGuard، و برای MASQUE یک کلید P-256 که کلادفلر برایش گواهی می‌دهد. همه در `files/warp/` گوشی می‌ماند.
   - **دروازه:** اول دروازه‌ی دفعه‌ی قبل؛ وگرنه اسکن IPهای `162.159.198.x`/`162.159.199.x` (و IPv6 ‏`2606:4700:103::1`) روی پورت‌های 443، 500، 1701، 4500، 4443، 8443، 8095.
   - **تونل:** MASQUE یعنی یک درخواست `CONNECT` با پروتکل `cf-connect-ip` روی HTTP/3 (QUIC) یا HTTP/2 (TLS روی TCP 443) با گواهی کلاینت؛ بسته‌های IP داخل آن می‌روند. ضد فیلتر: بسته‌ی آشغال قبل از دست‌دادن و تکه‌تکه کردن ClientHello.
   - **SOCKS5** روی `127.0.0.1:1819`.
4. **دروازه‌ی ۱** (`Engine.awaitSocks`): تا پورت 1819 واقعاً اتصال نگیرد جلو نمی‌رود.
5. **hev** (`Engine.startHev`): بسته‌های TUN را به آن SOCKS5 می‌دهد.
6. **دروازه‌ی ۲، تأیید واقعی** (`Probe.trace`): یک درخواست HTTPS از داخل تونل به `cloudflare.com/cdn-cgi/trace`؛ آی‌پی خروجی، محل و `warp=on` را از جوابش می‌خواند. فقط این‌جا «وصل هستی».
7. **وقتی وصلی:** ترافیک هر ثانیه، سلامت هسته هر ۲ ثانیه، پینگ هر ۳۰ ثانیه. اگر تونل افتاد خود هسته دوباره وصل می‌شود.

| شهر دیتاسنترها (آلمان، ترکیه) | `core/Colos.kt` |
| ظاهر | `ui/Theme.kt`، `ui/Icons.kt`، `ui/Portal.kt` (دکمه‌ی اتصال)، `ui/Screens.kt` |

## ساخت
همه چیز در گیت‌هاب ساخته می‌شود (`build.yml`): بار اول هسته حدود ۴۰ دقیقه، بعد از کش. فایل نصبی در Releases و روی main در تلگرام.
برای تلگرام دو Secret در همین ریپو لازم است: `TG_BOT_TOKEN` و `TG_CHAT_ID`.

فقط برای استفاده‌ی شخصی. مجوز: AGPL-3.0 (بخاطر هسته‌ی Aether)، جزئیات در `NOTICE`.
